1. 서버(Server)
 네트워크를 통해 클라이언트에게 데이터, 파일, 웹 페이지 등의 서비스나 자원을 제공하는
 컴퓨터 시스템
클라이언트(Client)
서비스를 요청하고 제공받는 사용자 장치(PC, 스마트폰)나
애플리케이션(웹 브라우저)을 의미합니다.

2. 서버와 클라이언트는 네트워크 기반의 ‘요청-응답’(Request-Response) 관계입니다. 
클라이언트가 서비스를 요청(Request)하면, 
서버가 이를 처리하고 응답(Response)하는 구조로, 
웹, 앱, 게임 등 대부분의 디지털 서비스에서 데이터를 주고받는 기초 모델입니다. 

1) 서버(Server)
  서비스 제공자: 데이터 저장, 파일 관리, 웹 페이지 서비스,
                       애플리케이션 실행 등 핵심 기능을 수행합니다.
2) 클라이언트(Client)의 역할 및 특징
   서비스 요청자: 웹 브라우저나 앱처럼 사용자의 인터페이스(UI)를 담당하며,
                        서버에 필요한 정보나 기능을 요청합니다.
   상호작용: 사용자가 서버와 통신할 수 있는 창구 역할을 합니다. 

3) 관계의 핵심
     의존성: 클라이언트는 서버가 제공하는 서비스에 의존하며, 
                서버에 문제가 생기면 클라이언트 기능도 멈춥니다.
    비대칭성: 한 대의 서버가 수많은 클라이언트의 요청을 동시에 처리할 수 있습니다.
               통신 프로토콜: 주로 HTTP/HTTPS 프로토콜을 사용하여 데이터를 주고받습니다. 

3. VS Code의 Live Server 확장 프로그램으로 실행시킬 때 나오는
   http://127.0.0.1:5500과 같은 주소는 내 컴퓨터를 임시 웹 서버로 활용하여 
   개발 중인 웹 페이지를 실제 인터넷 환경처럼 열어본다는 의미를 가지고 있습니다. 
   이 주소는 '서버'라는 개념과 다음과 같은 직접적인 관계가 있습니다.
   1) 주소의 구성 요소와 의미 (예: http://127.0.0.1:5500) 
     
    (1)  http://: 브라우저와 서버가 통신하는 규약(Protocol)을 의미합니다.
     127.0.0.1 (localhost): 루프백(Loopback) IP 주소로, 외부 네트워크가 아닌 
     내 컴퓨터(나 자신)의 네트워크 인터페이스를 가리킵니다.
     즉, "외부에서 가져오는 것이 아니라, 내 컴퓨터에 있는 파일들을 웹 서비스 형태로 불러오겠다"
     는 뜻입니다.
    (2) :5500 (포트 번호, Port): 내 컴퓨터 내에서 수많은 프로그램 중 Live Server라는 특정 프로그램이
         대기 중인 가상의 '문'을 뜻합니다.
         이 포트는 통상 5500번을 사용하지만, 이미 사용 중이면 5501, 5502 등으로 자동 변경됩니다. 

 2) 서버 개념과의 관계
    (1) 로컬 개발 서버 (Local Development Server)
        실제 웹사이트는 AWS 같은 원격 서버에 있지만, 개발자는 매번 거기에 파일을 올릴 수 없습니다. 
        Live Server는 내 컴퓨터 안에 간이 서버를 설치하여, 내 컴퓨터가 서버의 역할을 하게 만들어 줍니다. 

    (2) 진짜 서버 같은 환경 제공 (HTTP 프로토콜)
        파일을 더블 클릭(file://...)해서 열면 일부 스크립트나 기능(예: Fetch API)이 보안상 작동하지 않습니다. 
        Live Server는 HTTP 주소를 통해 파일을 서빙하므로, 실제 웹 환경과 동일한 조건에서 개발과 테스트가 가능합니다. 

    (3) 실시간 동기화 (Live Reload)
        서버는 웹 페이지의 변경 사항을 감지하여 브라우저에 신호를 보냅니다.
        Live Server는 코드를 수정하고 저장(Ctrl+S)하는 순간 웹 소켓을 통해 브라우저를 자동 갱신하여 새로고침 없이 즉시 결과를 반영합니다

4. Live Server 확장 프로그램은 HTML, CSS, JavaScript 파일을 편집할 때
 실시간으로 브라우저에 반영하여 확인할 수 있게 해주는 기능 

  1)실시간 미리보기 (Live Reload): 
     코드를 저장하면 브라우저가 자동으로 새로고침되어 변경 사항을 즉시 확인할 수 있습니다.
  2)로컬 개발 서버 실행:
     내 컴퓨터를 서버처럼 작동시켜 정적 및 동적 페이지를 로컬 환경에서 실행할 수 있습니다.
  3)간편한 실행: 
     VSCode 하단의 'Go Live' 버튼을 클릭하여 즉시 서버를 실행할 수 있습니다.
     코드를 수정할 때마다 새로고침을 할 필요가 없어 개발 속도와 편의성을 크게 향상시킵니다. 
 4)포트 변경 및 설정: 
    기본 포트(보통 5500)를 변경하거나 랜덤 포트로 설정하여 사용할 수 있습니다.
